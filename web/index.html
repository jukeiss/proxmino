Settings

General

Saved to data/settings.json on this computer. API keys go in the .env file and are never shown here.

Local models use this computer's CPU and GPU. Long sessions make it warm. Models unload two minutes after the last answer.

With cloud on, your messages, chat history and search results are sent to the provider you choose and handled under its terms. Keys stay in the .env file.

Reading aloud uses this computer's own voices. Dictation uses the browser's speech service; in Chrome that sends your audio to Google.

Brain

With Proxmino as the brain, your own trained model answers everything. Turn Cloud providers off as well to keep it fully offline; with them on, DeepSeek only steps in if your model is not running.

Uncensored mode

Adds an Uncensored tone you can pick per chat: swearing, dark humor, roasting and straight answers on adult topics. Other tones stay as they are. A few limits never change: nothing sexual involving minors, no instructions for serious harm, no doxxing, no fake images of real people.

Sending

Every send is logged. Even with no approvals, it still asks when an answer read web pages or another tool's output (text from outside could try to make it send something), when a message looks like a scam, and after the daily limit.

Models and router

Each tier is an ordered fallback chain of provider:model. The first one that responds answers. If none respond, any installed local model is tried.

Knowledge

API keys

Paste a key and press Save. Keys are written to the .env file on this computer (readable only by you) and are never shown again; this page only says whether each one is set. Only possible on this computer, not from another device.

Usage

Activity from saved chats on this computer over the last 30 days: answers, tokens and response time per model. This is not billing data; providers may count differently.

Memory

Facts and preferences added to conversations. Shared ones reach every agent; others only the agent they belong to (type /remember @forge ... in chat). Stored only on this computer.

Scratchpad

Open work each agent keeps for later (from Rakazo). With the Tools pill on, agents add and finish items themselves; each agent sees its own open items in every reply.
